Simple Registration Form

A clean and responsive registration form built using HTML, CSS, and JavaScript. It demonstrates real-time validation for user inputs and provides instant feedback for better user experience.

Key Features

Real-time input validation for name, email, and password

Error messages displayed under invalid fields

Submit button disabled until all inputs are valid

Responsive design that works on desktop and mobile

Simple, beginner-friendly front-end project

Technologies Used

HTML – for the structure of the form

CSS – for styling and layout

JavaScript – for validation logic and interactive behavior

Why This Project?

This project shows that you can:

Build interactive forms

Handle user input validation effectively
